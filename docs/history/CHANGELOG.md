# 变更记录

## 0.1.1（2026-10-25）

修复两个会导致「对话发不出去」的兼容性缺陷：

1. **非流式请求必定失败**
   WorkBuddy 服务端不接受 `stream:false`：真实请求返回 HTTP 400、业务码 `11101`（`Non-stream chat request is currently not supported`）。
   影响范围不只是关闭「流式输出」的聊天，还包括宿主所有辅助模型调用（自动标题、总结、记忆等走 `stream=false`）。
   现在传输层固定 `stream:true` + `Accept: text/event-stream`；当宿主请求非流式时，插件不再转发中间 `chunk`，只返回最终完整 `text`，由宿主一次性消费。

2. **工具历史无法配对时整轮对话报错**
   旧版遇到「孤立的工具结果」或「历史里引用了已停用的工具」会直接抛出
   `工具结果与历史调用无法配对，请重新开始会话` / `历史包含当前不可用的工具…`，导致该会话永久不可用。
   上下文裁剪、工具包被关闭、工具调用中断都会产生这类历史。现在按宿主语义降级处理：
   - 无法配对的工具结果直接丢弃（宿主对未匹配 `tool_result` 同样是告警后继续）；
   - 已停用工具的调用保留为助手文本，不再阻断后续轮次。

3. 版本号与设置界面文案同步更新。

### 验证

- 真机实网：修复后的请求体 `stream:true`，服务端返回 HTTP 200 / `text/event-stream`，
  `usage={input:16, cachedInput:0, output:73}`，思考与正文均正确解析。
- 同步回归：非流式请求体、孤立工具结果、停用工具历史、正常工具配对、流式工具标记 5 项全部通过。
