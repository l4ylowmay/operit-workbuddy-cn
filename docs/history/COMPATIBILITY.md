# 兼容限制与 Android 验收

本版是未完成真机验收的测试包。下面的未验证项目是实质交付限制，不因模拟测试通过而消除。

## 尚未解决 / 尚未验证

1. **Android 端到端未执行。** 当前环境没有连接的 Android 设备、ADB 或可用 KVM 模拟器。尚未证明发行 APK 实际导入、Java 桥的 Android Crypto/IO 重载、浏览器授权、加密重启恢复、真实推理、积分和 Android 系统工具执行均成功。
2. **账号与真实模型不可用。** 未提供 WorkBuddy 登录账号或授权后的会话；没有真实 Access/Refresh Token。已验证创建匿名授权会话，未完成浏览器授权，未发送模型推理。未登录配置响应 `code=0` 但 models 为 null，明确不算模型发现成功。
3. **400 / 11128。** 已移植并模拟验证 DSH 1.3.25 修复逻辑，但 WorkBuddy 可根据账号、客户端或系统内容继续拒绝请求。不会盲目重试或静默改账号；错误只展示 HTTP 状态和安全业务码。当前无法承诺旧问题在所有真实模型上都不复现。
4. **取消响应存在延迟。** 使用 Java 桥的同步 Android HTTPS 读取，宿主取消可能要等正在进行的 native read 返回；连接超时 15 秒，对话读取空闲超时 60 秒，累计读取限制 10 分钟。不能宣称已验证即时停止或 Android 后台长时间保活。
5. **历史工具必须仍可用。** 若历史包含当前工具列表之外的调用、结果无法配对，或历史结构被第三方插件改写，会明确报错并要求恢复工具列表或新建会话，不发送已知不合法的工具历史。
6. **文本通路。** 未支持图片/音频/视频直传、带图片的工具结果、多模态历史和模型视觉处理；请关闭 Operit 的相关直接处理开关。读取设备屏幕截图后的视觉理解不在本版验收范围。
7. **思考参数依模型能力。** 使用已知 `reasoning_effort` 字段与服务返回的档位映射；`onlyReasoning` 模型无法保证关闭思考。未验证所有模型是否接受同一档位；不支持时应关闭思考或选择支持的档位。
8. **账号与模型选择为全局默认。** 多个 Operit 配置共用当前账号，没有每会话账号路由或负载均衡。请求开始后以已取出的账号快照发送；切换/删除账号不会撤销已发出的请求。WorkBuddy 服务端刷新、撤销及 Refresh Token 轮换真实行为待验证。
9. **积分范围。** 支持个人资源余额与企业配额，不包含今日消费分页、账单明细和积分到期明细；个人资源达到 100 项时拒绝给出可能不完整的总额。接口字段变化时显示错误，不把未知余额当零。
10. **存储边界。** 使用应用私有 noBackup 目录与设备密钥，不可跨设备导出恢复。密钥失效时不能自动恢复令牌，需要在设置勾选确认后清空本机凭据并重新登录。不能隔离同 UID 内其他恶意插件，也未验证 Root/定制系统。
