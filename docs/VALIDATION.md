日期：2026-10-25（北京时间）。设备：三星 SM-F9710，Android 17，原版 Operit 1.12.2。使用正常 ADB 与应用现有 Java 桥，全程无 Root、解锁 BL、APK 修改或分区写入。

## 已验证

- 已修复实际故障：直处理开关不再导致纯文字请求被插件主动拒绝。
- 当前账号目录返回 19 个 CLI 模型，均声明 `supportsImages:true`；仅对下表模型完成真实调用，不能推导全部模型已实测。

- 截图测试正确识别 “WorkBuddy 中国区” 和 “0.2.0”；红色样图被正确识别；多轮口令正确。
- 聊天 UI 在当前 CHAT 绑定下返回 `WB020UIOK`。登录与模型发现不是唯一通过依据。
- 图片生成：WorkBuddy 集成媒体服务 `hy-image-3.5-wb` / `copilot-image` 返回同步 `completed`；PNG 已下载并注册到 ImagePoolManager。生成描述为白底红色圆形图标。
- 生成协议模拟回归覆盖同步结果、异步查询、业务失败、无重复提交、短期凭据与 Access Token 分流；另有图片适配和 SSE 截断回归。
