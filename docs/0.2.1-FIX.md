# 0.2.1：真实聊天附件解析修复

2026-10-25 20:03 的餐食图片对话：宿主直接图片开关为 true，JPEG 成功入池，实际模型为 step-5-preview；模型却只能看到附着图片的文字提示。

从手机同版发行 APK 的 resources.arsc 提取到真实模板 `<link type=image id=%1$s>图片</link>`。源码 XML 写作带引号形式，但 Android 资源编译后引号被消费。0.2.0 属性解析器要求引号，因而静默跳过实际图片。0.2.1 接受带引号、无引号、混合和转义形式，增加真实发行模板回归测试；共 23 项通过。

此前手工构造带引号标签的 Provider 测试不能替代正常聊天附件的端到端验证。视频上游 502 与音视频直接输入未实现的边界不受此修复影响。

另修复历史图片缓存过期时阻断新附件的问题：过期的旧图片替换成明确说明“未附带图像内容”的文字，不伪装成有效附件；当前消息的图片缺失仍明确报错。追加后共 25 项本地测试通过。
